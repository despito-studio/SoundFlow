# Підтримка SoundFlow

Офіційні завантаження й примітки до випусків доступні в [Releases](https://github.com/despito-studio/SoundFlow/releases). Для технічних питань, помилок і пропозицій використовуй [Issues](https://github.com/despito-studio/SoundFlow/issues).

## Перед зверненням

Перевір актуальність версії та пошукай схоже повідомлення серед відкритих і закритих Issues. Portable-версію потрібно розпакувати повністю; для звичайного запуску використовуй `SoundFlow.exe` з кореня її папки.

У зверненні вкажи:

- Версію SoundFlow та Windows, інсталятор чи portable.
- Кроки, після яких виникає проблема, та очікуваний результат.
- Текст помилки, знімок екрана або короткий запис, якщо вони допоможуть.
- Для візуальних проблем — масштаб Windows і розмір вікна; для пошуку та відтворення — джерело й публічне посилання на трек, якщо проблема стосується конкретного треку.

Перед публікацією прибери з журналів і зображень токени, електронну пошту та інші особисті дані. Не надсилай повний каталог профілю чи базу медіатеки.

GitHub Issues є публічним каналом. Про вразливості повідомляй за [SECURITY.md](SECURITY.md), про порушення правил — за [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Умови персональної чи комерційної підтримки узгоджуються окремо; Issues не встановлює строків відповіді.
