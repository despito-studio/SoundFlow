SoundFlow concentric corners

Reference: https://github.com/diip3sh/tailwindcss-concentric
Copyright (c) 2026 diip3sh, MIT.

SoundFlow implements the documented edge-distance rule in native Dart:
flutter_app/lib/concentric.dart. The native installer consumes geometry exported
from that same implementation by flutter_app/tool/export_installer_icons_test.dart,
using flutter_app/lib/installer_design.dart for the reference layout and action groups.
This is a Flutter adaptation, not a Tailwind or CSS runtime dependency.
The source palette, CSS selectors, generated styles,
audit CLI, branding and agent skill are not bundled. SoundFlow's geometry tokens,
explicit layout offsets and native Windows alpha contour are its own.
