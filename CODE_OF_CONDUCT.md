# Правила поведінки

Ці правила діють в Issues, pull requests, обговореннях та інших просторах SoundFlow, які модерує Despito Studio.

## Повага до учасників

- Обговорюй рішення й поведінку програми, зберігай повагу до людей.
- Пиши конкретно, враховуй контекст і приймай обґрунтований зворотний зв’язок.
- Поважай приватність, авторські права та особисті межі інших учасників.
- Давай іншим можливість брати участь незалежно від їхнього досвіду чи походження.

Образи, переслідування, дискримінація, погрози, сексуальні домагання, розголошення приватних даних і спам неприпустимі. Так само неприпустимий тиск на учасників із вимогою безоплатної роботи або негайної відповіді.

## Модерація

Команда може редагувати чи приховувати повідомлення, закривати обговорення та обмежувати доступ до просторів проєкту. Рішення враховує зміст, серйозність і повторюваність порушення. Учасник може попросити команду переглянути рішення, надавши новий контекст.

## Повідомлення про порушення

Для публічного порушення скористайся дією GitHub **Report content** або зверни увагу модераторів у відповідному обговоренні. Для погроз, переслідування чи розголошення приватних даних використовуй [GitHub Abuse Report](https://github.com/contact/report-abuse).

Не публікуй чутливі докази та особисті дані у відкритому Issue. Команда розглядатиме повідомлення в межах доступних каналів і повноважень модерації.
