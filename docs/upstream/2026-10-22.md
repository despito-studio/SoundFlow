# GitHub 3.5.1 → SoundFlow Flutter

Перевірено 10 комітів `despito-studio/SoundFlow`, від `5bf75f7` до `4e51495` включно. Зміни перенесені вибірково в поточну Windows-версію на Flutter. Slint-застосунок і його збірка не відновлюються.

| Зміна GitHub | Результат у Flutter-версії |
| --- | --- |
| Імпорт профілю SoundCloud як окремих плейлістів, імпорт `/sets/…` | Перенесено. Для коротких відповідей SoundCloud додатково завантажуються треки, представлені лише ID. Запис плейліста виконується одним збереженням, зі збереженням перевірки активного акаунта. |
| Відкриття плейлістів після імпорту | Адаптовано до нашої навігації: відкривається медіатека. |
| Резервні рекомендації SoundCloud з урахуванням мови | Перенесено в наявне автоматичне продовження черги. |
| Rose / Violet / Ocean | Додано як кольорові варіанти нашої системи поверхонь. Геометрія, відступи, Dock та Island збережені; Slint-матеріали не копіюються. |

| Slint UI, `application.rs`, clipboard workaround, iOS-мокапи | Не переноситься в робочий Flutter-застосунок. |

Окремо за запитом користувача виправлено гучність: логічне значення повзунка перетворюється на амплітуду за `gain = volume²`; `0` залишається повною тишею. Нормалізація тепер лише послаблює сигнал до цільового рівня й не підсилює тихі фрагменти до 4×. Гучність Windows не змінюється. У Dock показується відсоток гучності.

Версії Rust і Flutter узгоджені як `3.5.1` / `3.5.1+1`. Git HEAD не пересувався поверх незакоміченої міграції: це вибіркове перенесення змін, а не заміна робочого дерева на Slint-гілку. SHA останнього опрацьованого upstream записаний у `state.json` поруч із цим документом для наступного оновлення.

До змін збережено архів вихідного коду, патч і список видалених файлів у `output/upstream-sync/20261022/`. Бібліотека користувача не мігрується й не видаляється цим оновленням. Перевірка обмежена збіркою, аналізом Dart і оглядом фактичного Flutter-рендера; автоматичного відтворення звуку та зміни Windows mixer не виконувалося.
