У **SoundFlow 1.1.0** оновлено Dock і типографіку застосунку.

## Що змінилося

- **Окремі елементи Dock.** Прев’ю пісні, кнопки відтворення та службові дії розділені. Play/pause розташована по центру, а блок пісні й група кнопок справа мають однакову ширину.
- **Гучність при наведенні.** Вертикальний повзунок відкривається над кнопкою. Клік вимикає або вмикає звук; попап залишається відкритим під час переходу курсора до повзунка.
- **Прев’ю поточної пісні.** Назва й автор видимі в Dock. Натискання відкриває метадані та перемотування; жест угору розгортає пісню й чергу.
- **Onest і Montserrat.** Onest використовується для основного тексту, Montserrat для заголовків. Шрифти включені до застосунку й доступні без інтернету.
- **Керування клавіатурою.** Уточнено роботу фокусу, Escape та повернення до кнопки після згортання плеєра. Попапи враховують зміну розміру вікна й налаштування зменшення руху.

## Оновлення з 1.0.0

Відкрий SoundFlow та натисни **«Оновити»**, коли з’явиться повідомлення про нову версію. Програма завантажить пакет, перевірить його й перезапуститься. Медіатека та налаштування зберігаються.

Службові пакети оновлень публікуються через GitHub Pages. Для автооновлення не потрібно завантажувати інсталятор вручну.
