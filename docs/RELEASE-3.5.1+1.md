# SoundFlow 3.5.1+1 для Windows

Інтерфейс Flutter та аудіоядро Rust. ZIP та інсталятор зібрані локально
на Windows-ПК й завантажені в цей реліз без повторної збірки на GitHub.

- Discovery, медіатека з улюбленим і плейлістами, профілі та попап підключень.
- Оновлений Dock, фон #181818, лінійне згасання Header та AnimateIcons.
- Компактний Dynamic Island зі згладженим контуром і круглою обкладинкою.
  На робочому столі він видимий постійно, в активних програмах прихований.
- Виправлення перемотування, шкали гучності та підготовки аудіоданих.
- Перенесені імпорт SoundCloud, рекомендації та варіанти іконки застосунку.

Встановлення: запусти `SoundFlow-3.5.1-Setup.exe` або розпакуй
`SoundFlow-3.5.1-windows-x64.zip` і запусти `SoundFlow.exe`.
Зберігай DLL, `data`, `resources` та `media-provider` поруч із програмою.
Дані користувача залишаються в `%APPDATA%\app.soundflow.desktop`.

Версія Flutter: `3.5.1+1`; версія Rust-ядра: `3.5.1`.
SHA-256 локальних файлів наведено в `SHA256SUMS-3.5.1.txt`.
