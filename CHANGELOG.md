# Changelog

## 1.0.0 — стабільна лінійка продукту

Початкова версія нової стабільної лінійки SoundFlow. Статус публікації та готові завантаження — у [Releases](https://github.com/despito-studio/SoundFlow/releases).

- Прозорий плаваючий Dock із жестом розгортання в поточний трек і чергу.
- Оновлені налаштування, оформлення та пошук із найкращим збігом, авторами й історією.
- Нативний інсталятор із шрифтом Onest, спільними іконками та плавними переходами станів.
- Оновлення через Velopack із пакетами на GitHub Pages, перевіркою цілісності та автоматичним перезапуском.
- Інсталятор і керований portable ZIP як два користувацькі завантаження.
